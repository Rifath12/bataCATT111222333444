# Real Mandarin three-voice evaluation

The timing panel contains 18 disjoint excerpts (424.97 s) from three AliMeeting Test source meetings that had no model scoring in the earlier project. The source meetings each had four people. In every chosen excerpt, the forced-aligned activity reference has exactly three distinct annotated identities and a 250 ms inactivity guard for the fourth person. The panel contains 26.25 seconds when all three identities speak and no frames with four active identities. The 62 exact-three bouts have a median duration of 250 ms. Twenty-two bouts last at least 0.50 s. The longest bout lasts 1.48 s.

The test uses R8002_M8002, R8005_M8007, and R8005_M8008, with disjoint published speaker identities. R8005_M8007 and R8005_M8008 were previously examined as candidates for a different test. Earlier scoring never used their audio. These speakers are held out from project calibration. The original contents of pretrained model training sets were not audited here.

The metadata-only selection collects fourth-speaker inactivity spans of 8–75 s after the guard, retains spans with at least 0.40 s of three-way speech and all three identities represented in public timed tokens, then uses weighted interval scheduling to maximize reference three-way speech across at most six nonoverlapping intervals from each recording. Ties favor longer total exposure, then earlier end times. For full waveform and transcription evaluation, two of the selected excerpts per source are ranked using only reference three-way duration. They total 164.76 s, including 10.87 s of exact-three speech in 27 bouts, and 1,146 reference characters. The data files and selection were frozen before any new predictions were generated.

The source mono WAV is channel 0 (the first microphone channel) from the PCM-16 16 kHz eight-channel mixture. No filtering is performed while extracting this channel. The archive has a fixed source URI, source interval, audio SHA-256, cropped aligned RTTM SHA-256 and a timed character reference SHA-256 for every clip. Native diarization, waveform separation, and transcription consume only audio and automatically inferred timing. The reference never enters inference.

The activity denominator is the clock duration with exactly three concurrent identities in the forced-aligned AliMeeting room-microphone RTTM on the 10 ms grid. Activity metrics use a zero collar and one best whole-clip identity mapping. The results include exact-three precision and recall, the partial speaker-time recall giving credit to each identified speaker, and diarization error on all frames. These are different quantities.

The text source is word-level alignments to individual recordings made public by MultiTalkBench. The timed token contents exactly reproduce the official TextGrid transcript after normalization (38,733 characters, zero edits on all 12 source speaker files). The 18 clips include 2,888 normalized reference characters, of which 395 have their midpoint in reference exact-three activity when evaluated on the exported 10 ms grid. The six waveform/ASR excerpts include 153 such characters. Per-character timing is externally model aligned. Short boundaries therefore have timing uncertainty. Relative reference times are clipped to each excerpt. The overlap-conditioned scorer counts per-speaker character matches, substitutions, insertions and deletions with a time constraint. Report whole-clip character error and overlap-conditioned error separately. When hypothesis character timestamps are absent, they are interpolated within their source utterance, and the metric must be described as a timing-based estimate.

The frozen width-15 timing baseline on 18 clips recognized all three for 21.33 out of 26.25 seconds (81.26% recall and 50.33% precision). Partial triple speaker-time recall was 93.17%, and pooled zero-collar DER was 17.68%. On the six-clip transcript shortlist the same timing found all three for 7.97 of 10.87 seconds (73.32% recall and 48.93% precision). Triple speaker-time recall was 90.10%, and pooled zero-collar DER was 20.16%.
