# Three-way Mandarin separation with a single far-field microphone

In eight confirmation overlaps from a second AliMeeting room, the tested blend raised median fixed-speaker waveform alignment from 15.64% to 18.65% and median quiet-speaker alignment from 9.58% to 16.99%. All three speakers reached the 96% target in 0 of 8 clips with either method. Individual tracks reached it in 0 of 24. Ten tracks gained alignment, eleven lost alignment, and three tied within 1e-8. Three losses were 27–42 percentage points. The candidate was rejected as a production replacement.

## Data and acceptance test

Build the two single-channel controls with the supplied known-source Mandarin panel protocol. For each meeting use the actual far-field array's first channel, a separate enrollment recording for each anonymous participant, and the first eight triple events, t01 through t08, ordered chronologically. R8004_M8006 is the development meeting and R8005_M8007 is the confirmation meeting. The two rooms contain different speakers. The eight 1.536-second events include 4.834 seconds and 4.841 seconds, respectively, of simultaneous target activity. These controlled overlaps replay disjoint, naturally spoken turns captured in the room. The test supplies three-way window boundaries and participant count.

For each recording, generate candidate tracks from the single mixture only. Use each room's separate A/B/C enrollment WAVs to compute the existing `enrolled_order.fit_templates` templates. Run `assign_tracks` separately on each method's three unordered outputs. Compare the resulting fixed A/B/C output to the same-label known sources using `waveform_acceptance.evaluate_case` and the reference activity and exact-three masks. Pass at 96% or 98% if all three speakers meet that target-aligned energy threshold and preserve at least 96% of eligible active time within the existing 12 dB target-level tolerance. Diagnostic permutation scores maximize the sum of squared full-clip waveform correlations against the three references over all six one-to-one mappings. They measure source recovery with reference-assisted identity assignment.

## Systems

`model_revisions.json` contains revisions and file digests for the three candidate systems and Libri3Mix fallback. Fetch these assets with `python fetch_architecture_assets.py --models study_models`. The upstream MossFormer2 code is pinned by Git blob digests. Install the repository's mono_wave requirements and use its model downloader to prepare the existing ReCorrNet assets. Use CPU float32 with one compute thread. The tested environment used PyTorch 2.6.0+cpu and SpeechBrain 1.0.3.

1. Run the released ReCorrNet using bounded batches and fused attention on the 16 kHz mix. Use the released `select_tracks` eligibility test on the second and first passes. If both fail, resample to 8 kHz by polyphase filtering, run the pinned Libri3Mix SepFormer and `SpectralRefiner`, scale the sources with the release's `scale_sources`, and return the outputs to 16 kHz. Five development and four confirmation clips required the actual fallback.
2. Feed the original 16 kHz mixture separately to the TCC300 clean and noisy three-source SepFormer checkpoints. For WSJ0-3Mix MossFormer2, resample to its native 8 kHz, call the official model's forward method and resample its three output signals to 16 kHz. In each case rescale the three source gains with the released ridge-fit equation. Check every model parameter on load. This benchmark leaves each model's own bandwidth intact.
3. For a candidate blend, compute the 3×3 signed full-clip normalized cross-correlations between all centered incumbent and candidate waveforms. Align candidate indices using the one-to-one mapping that maximizes the sum of squared correlations. Correct each selected polarity. On each incumbent stream where squared agreement is at least 0.25, average the original and aligned candidate samples with equal weights. Keep the incumbent on other streams. Enroll and score the resulting blend independently, as in step 1.
4. Other predeclared development methods were standalone replacements, fallback-window rescues using the candidate's own mixture-fit gate, and a per-stream medoid of all four aligned systems using median squared correlations. Selection first maximized the count of enrolled 96% plus 98% joint passes, then median quiet-voice fidelity and then median track fidelity. The noisy TCC300 agreement blend won the development comparison and was frozen before scoring its predictions in confirmation.

The JSON result includes every compared development method, the full set of paired fixed-label tracks for the selected candidate and the incumbent, label permutations, retention, the quietest source, joint passes, cohort hashes and confirmation gains and losses.
