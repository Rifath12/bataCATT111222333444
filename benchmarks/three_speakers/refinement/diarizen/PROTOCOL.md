# Independent confirmation of the third speaker

The verifier uses a single Mandarin room microphone. Nemotron supplies three session-level identities and their activity history. A separately trained compact DiariZen WavLM model supplies independent acoustic evidence. The tested checkpoint has four local slots and eleven powerset outputs, covering silence, four individual speakers, and six speaker pairs. It directly models up to two simultaneous speakers. To infer the harder three-voice case, the verifier uses pair probability mass, pair competition, sorted slot marginals, model entropy and the Nemotron posteriors.

The DiariZen input window is 16 seconds with an 8-second hop, weighted averaging in overlaps, and 10 ms interpolated outputs. Labels are absent during feature extraction. A regularized logistic regression learns the three-voice decision from the 45 REAL-T development excerpts. Three folds grouped by session produce out-of-fold predictions for threshold selection. The operating objective is exact-three F1 plus 0.2 times three-way speaker recall minus 0.3 times overall diarization error. The classifier is refitted on all development excerpts. Its coefficients and thresholds are stored in JSON.

The same-model control uses the identical training rule and Nemotron features alone. The independent verifier edits the previous calibrated decoder’s three-way timing. The full-count variant also uses DiariZen’s silence, single-voice and two-voice posteriors elsewhere. A separate confirmation ablation applies the verifier as a veto to the preceding experimental two-pass decoder. A veto removes the lowest-ranked voice and preserves the other two. No threshold is selected on the transfer corpus.

DiariZen source revision is `844f5555b0a98acd0931511fc641a8c5b8ba92c7`. The tested weights SHA-256 is `2f65bc7772c92f90b6ff2ef1d7bdd068584828ed4578e6e48754380220aae979`. The authors list AliMeeting among the pretraining corpora and license the weights for non-commercial use. The four-voice local slot count does not establish four-person simultaneous speech capability. Use `extract.py --model-dir MODEL_DIR --manifest FILE --output FEATURES` in the upstream DiariZen environment, repeating the manifest argument for each split. The `verify_count.py` benchmark uses the existing `multiview_score.py` and prior project helpers on PYTHONPATH. Provide the development manifest and Nemotron caches, frozen prior profile, DiariZen feature folder, one or more `--test NAME MANIFEST NEMOTRON_CACHE` arguments, and `--output REPORT`. Use `--save-frozen PARAMETERS` to write the fit or `--from-frozen PARAMETERS` to reuse it. `confirm_prior.py` compares the previously calibrated two-pass decoder with the independent veto, using its published threshold of 0.125. The code and weights evaluate recorded audio offline.

For an unlabelled mono file, run `extract.py --audio RECORDING.wav --model-dir MODEL_DIR --output FEATURES` along with the existing two-pass Nemotron posterior exporter. Run `confirm_prior.py` with the 45-clip development manifest and caches, prior profile, frozen verifier, feature directory and `--predict RECORDING.wav NEMOTRON.npz TIMING.json`. The JSON gives anonymous A/B/C segments directly consumable by the existing renderer. Offline lookahead and a second network are required.
